# 4:3 显示与输入检测更新 · 2026-10-28

本版先保留原版 4:3，不做宽屏视野适配。

## 第三版：兼容全屏与无边框

实机确认：主人应用第三版并自行启动游戏后回复“可以了”，确认本机当前显示修复可用。此确认不扩大为其他电脑或所有手柄的兼容性验证。

主人实测第二版能够进入游戏，但“全屏/无边框”仍有标题栏；确认角色选择菜单的一处偏移可接受，游戏内 UI 正常。主人选择兼容全屏、优先稳定，因此第三版保留现有 HUD 缩放，不修改菜单/游戏内布局。

本版从原生创建窗口时移除标题栏与框架，覆盖主屏；创建设备后再次确认样式。兼容全屏和无边框采用同一窗口呈现路径，均不切换显示器独占模式。完整 4:3 画面呈现在居中目标矩形，黑边由不接受输入的黑色子窗口维护，避免切出返回后残影。

为满足 Direct3D9 对局部等比呈现的要求，此路径使用单缓冲 COPY、关闭 MSAA；抗锯齿选项仅在普通窗口生效。其他现有特效和 HUD 缩放保留。同步修正上游 Reset 顺序，先释放补丁自建默认池资源，再重置，成功后重建。

隔离桌面测试实际创建 640×480、1440×1080、2880×2160 设备，主/额外交换链 Present、释放资源后的 Reset 及重置后 Present 均成功；样式检查无标题栏。测试桌面未切换到主人桌面。20 项 Python 回归及隐藏输入、显示控件检查通过。真实游戏中的黑边像素、切出返回仍需应用后复核。

## 第二版修正：本机启动即退出

首版在主人 4K 屏幕上选择 2880×2160 后，出现 Can't find DisplayMode、Can't use format。原因是本地补丁修改了客户端分辨率表，却未把该尺寸补入客户端查询的模式枚举缓存。第二版在确认窗口模式支持对应颜色格式后补全该缓存；不更换启动器、不调整个人配置或存档。

新增静默 x86 图形接口探针对照：本机原始列表中 2880×2160 为 0 项，修正后两种颜色格式共 2 项；640×480、1280×960、1440×1080、1920×1440、2880×2160、916×687、7680×5760 共 7 种尺寸通过，重复添加不增项。独立审查未发现本次枚举修正的阻塞问题。这仍未验证游戏实际创建设备或完成渲染，需主人按原先失败的无边框模式重新启动确认。

## 使用

启动器 → 画面设置 → 显示模式：

- 无边框全屏：推荐；画面等比铺至屏幕可用范围，在宽屏显示器上左右留黑边。
- 普通窗口：按“窗口尺寸”选择，过大的窗口会自动缩小以适合主屏。
- 全屏模式（兼容全屏）：与无边框共用窗口呈现路径，不切换显示器独占模式。切换显示模式或渲染引擎后需要退出并重新启动游戏。

所有模式都让客户端本身处于窗口状态，避免原生全屏失焦主动结束的代码路径。当前版本不提供传统独占输出；按主显示器计算尺寸，尚未加入独立的显示器选择。

启动器 → 工具与维护 → 手柄与键盘：

- 重新扫描 XInput 和 Windows 游戏控制器（WinMM）接口。
- 选择测试设备，观察按钮位图、摇杆轴、方向帽或左右扳机数值。
- 在测试窗口内按键检查键盘；按键不保存到日志，不在窗口外监听。
- “Windows 手柄设置”打开系统游戏控制器面板。

WinMM 并非完整 DirectInput 枚举，同一手柄可能出现在两种接口下。检测成功不等于游戏已经兼容；本版未加入输入转换、驱动安装或外部按键映射。请先连接手柄再启动游戏，在游戏内 Options 的 Pad / Keyboard Config 配置键位。Xbox 类手柄若只有测试窗口有响应，需再根据具体型号确认兼容方式。

## 失焦跳出的确认范围

该反馈来自其他用户的电脑，主人本机目前似乎正常。已在本客户端反汇编中找到原生全屏的 WM_ACTIVATE 失焦退出分支，并调整配置避免使用原生全屏；**尚未确认反馈用户的实际退出原因，也未证明对方机器已修复**。

请反馈用户优先选择无边框模式复测“点击其他窗口/Alt+Tab 后再切回”。若仍退出，收集 Windows 版本、显卡及驱动、所选显示模式/渲染引擎、手柄型号和连接方式，以及退出时间附近的 launcher.log、Client/log/error.log。分享日志前可遮掉账号、聊天等个人信息。

日志新增实际显示模式、4:3 内部尺寸和可获取时的客户端退出码。退出码为 0 也可能是客户端主动结束，不能据此断言没有故障。

## 验证与限制

- 20 项自动测试通过：显示配置、边界尺寸、注册表写入失败阻止启动、原有 CTRLBUF 尾部保留、XInput 数据/断线、原有掉落和备份功能。
- 上述 Python 测试没有覆盖客户端的原生模式枚举，未能发现首版启动回归；第二版增加了上述 7 种尺寸的原生接口对照验证。
- 隐藏 Tk 输入窗口检查通过：无设备、键盘回调、模拟手柄数据、断线、单实例、关闭时取消定时器；未向桌面发送按键。
- 原有启动器布局与持久化检查在 980×660、1180×800、1399×773 和不同字体缩放下通过。新增输入窗口使用滚动内容和固定底部按钮。
- 原生补丁 Win32 Release 编译通过；本机独立客户端曾成功显示标题画面。桌面测试由主人按 Esc 停止，全屏/无边框、关卡内切出及其他用户电脑的验证尚未完成。
- 本机实际读到了 XInput 与 Windows 控制器接口及轴数值；没有通过人工按键验证所有实体设备或全部游戏内映射。

## 更新与回退

关闭游戏和启动器，先备份旧的 `PSOBB一键单机启动器.exe`、`Client/d3d8.dll`。把小型更新包内同名文件和 Client 子目录复制到游戏根目录，再通过新版启动器启动游戏。两个文件必须成对更新。包内不含玩家存档和个人 launcher_ui.ini，不替换原来的完整游戏 ZIP。

如需回退，关闭游戏和启动器后恢复上述两个备份；新版生成的 `Client/launcher_display.ini` 可保留，旧补丁不会读取。启动器首次使用新显示模式默认选择无边框；原有游戏倍率和窗口尺寸选择继续保留。

开发资料包含 Python 源码、原生补丁源码与来源/许可证。原生构建说明见 `native/psobb_widescreen/LOCAL_CHANGES.md`。
