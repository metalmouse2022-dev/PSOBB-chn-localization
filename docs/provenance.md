# 来源、许可与发布边界

本仓库整理 PSOBB 汉化工具、单机启动器源码及技术经验。公开可见不等于获得统一的开源再授权；本次整理没有替项目作者选择新的开源许可证，也没有把第三方内容重新归属为项目自有代码。复用时应分别核对相关文件的声明及权利人的许可。

## 工程内工具与技术文档

Python 启动器、数据调整工具、翻译工具、回归测试及中文技术笔记从本地工程中选取。发布目录与游戏工作目录分离，不复制旧 Git 历史；公开副本的必要适配及校验结果见发布记录。

这些工具依赖用户自行准备的匹配客户端、服务端或资源。源码中的文件名、结构常量、已知哈希和少量自造测试数据用于说明格式与兼容范围，不表示仓库提供相应游戏内容或拥有该游戏内容的分发权。

## 原生显示补丁

本地来源记录指定上游 [anzz1/psobb_patches](https://github.com/anzz1/psobb_patches)，固定提交 `3d487ba5323b66d8795874f4edb0c82991cfbab6`，子目录 `psobb_widescreen`。原 d3d8to9 文件的头部注明 Patrick Mours 的版权及 [crosire/d3d8to9 许可入口](https://github.com/crosire/d3d8to9#license)；工程已有 `LICENSE.md` 允许在保留版权、条件和免责声明的前提下分发源码或二进制。公开涉及文件时须一并保留这些声明。

`WideScreen.c` 保留对原作者 tofuman 的致谢。本地新增的模式枚举、窗口呈现等修改不改变原有第三方声明。该补丁包含针对 MTethVer12513 的地址和指令检查，不应当成所有 PSOBB 客户端的通用补丁。

完整上游工程还包含 Microsoft DirectX SDK 头文件及库、NVIDIA NVAPI、SMAA 代码和查找纹理。它们有独立来源和声明，不能由 d3d8to9 的许可统一覆盖。此次发布排除 SDK 库、纹理 `.dds`、内嵌查找纹理数据及编译产物；需要完整构建时，应从相应上游或正式 SDK 自行取得依赖并核对许可。源码修改部分与完整可构建上游工程应按 README 指引组合，不能把被排除依赖误认为已经随仓库提供。

本地原工程的 Visual Studio Debug 配置曾带有上游作者机器上的构建后复制路径；该路径不应进入可复现指令。构建应显式选择适当配置，并把输出放入自己的隔离目录。

## 服务端结构与概率资料

既有诊断引用了 [DaanVandenBosch/tethealla](https://github.com/DaanVandenBosch/tethealla) 的结构与掉落逻辑，以及 [fuzziqersoftware/newserv](https://github.com/fuzziqersoftware/newserv) 的格式/静态数据。它们帮助解释概率编码、成长表或任务格式；不能仅凭结构相似断言本地服务端就是某个未修改的上游版本。

本仓库不复制 `.ui-review/audit/` 中的整份第三方服务端源码快照，也不分发 Tethealla/newserv 可执行文件。需要查看实现时直接追溯上游，并遵守各自仓库许可。服务端程序、真实掉落表和玩家数据须另行合法取得。

## 音频兼容层

DSOAL 来自 [kcat/dsoal](https://github.com/kcat/dsoal)。本地历史记录所用版本为 r697 Win32。本仓库保留隔离/恢复脚本及已知文件哈希，不上传 `dsound.dll`、`dsoal-aldrv.dll` 或其他第三方音频二进制；不把脚本中的哈希识别解释成对未知 DLL 的兼容承诺。

故障含义可参阅 [Microsoft 的 NTSTATUS 错误码资料](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-erref/596a1078-e883-4972-9bbc-49e60bebca55)。`0xc0000142` 只说明 DLL 初始化失败，具体故障模块仍需对应机器上的证据。

## 翻译服务与依赖

`psobb_api_translator.py` 及相关批处理脚本包含 Gemini API 调用逻辑；API 工具额外依赖 `requests`。保留这些源码不表示本次发布调用了服务、验证了候选模型名称或授权上传游戏文本。模型可用性、价格、配额与服务条款应在实际使用时另查官方资料。

实际使用 API 前应先确定数据范围、费用和项目授权，密钥从环境变量或本机私有配置读取；不要提交 `.env`、认证配置、请求日志或响应中的敏感内容。若选择手工翻译，可使用导出、分批、合并及本地预检流程，无须运行 API 调用。

- 构建缓存、`.obj`、`.lib`、打包成品、历史完整工程副本及无法审查的临时目录。

排除发布不等于删除本地文件。原工程、备份和用户存档保持原位。仓库中的无资源测试与静态检查，不能替代用户自行准备匹配输入后的回读、构建及游戏内验收。
